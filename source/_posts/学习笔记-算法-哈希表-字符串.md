本题为字符串子串的经典范式，即如何在线性时间O(n)内找出一个字符串中不含重复字符的最长子串长度？ 该问题本质是将暴力枚举，优化为以每个字符结尾的递推思想。

## 题目

![image](/img/posts/image-ms4dodds.png)


## 字符位置记录使用数组（或哈希表）

我们需要在遍历过程中，实时查询当前字符上一次出现的位置，这本质上是字符→最近下标的映射。既然这样我们就可以想到用数组或者哈希表来实现。

我们可以使用一个固定长度的数组替代更通用的哈希表，因为字符的 ASCII 范围是 0~255，数组可直接以字符的 ASCII 码为索引，实现 O(1) 的查询与更新，且常数极小。

第一步：初始化，将所有位置设为 `-1`，表示从未出现过。

第二步：查询，遍历到字符 `s[i]` 时，通过 `lastPos = map[s[i]]` 获取上次出现位置。

第三步：更新，处理完当前位置后，将 `map[s[i]]` 更新为 `i`。

## 前一个位置的最长无重复——滚动变量 pre

 设 `pre` 为 前一个位置`（i-1）`结尾时，最长无重复子串的合法窗口的左边界前一位。例如，若 `i-1` 结尾的最长无重复子串是 `[L+1, i-1]`，则 `pre = L`。

状态转换： 当前位置 `i` 结尾时，其左边界由两个因素决定：

当前字符上次出现的位置

由数组获取，`i `结尾的子串不能包含该位置，否则字符重复。左边界至少为` lastPos`。

前一个位置的合法窗口的左边界前一位位置

`i `结尾的子串必然包含前一个子串作为前缀，因此也不能包含 `pre` 位置的字符。左边界至少也为` pre`。

当前位置 `i` 的 合法窗口的左边界前一位位置= `max(pre, lastPos)`

## Code

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        // ASCII字符 0~255
        int lastPos[256];
        // 全部初始化为 -1
        memset(lastPos, -1, sizeof(lastPos));
        int pre = -1;
        int ans = 0;
        for(int i = 0; i < s.size(); i++)
        {
            char ch = s[i];
            // 更新障碍边界
            pre = max(pre, lastPos[ch]);
            // 窗口长度 i - pre
            ans = max(ans, i - pre);
            // 更新当前字符最新下标
            lastPos[ch] = i;
        }
        return ans;
    }
};

```
