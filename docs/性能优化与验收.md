# 网站性能优化与验收

## 2026-09-09 结果

测试环境为 Windows、Chrome 152、Intel Core i9-14900HX。本地静态服务分别运行修改前的隔离副本和当前构建，每个页面测量三次。由于无网络传输，LCP 仅用于同机回归，不能代替线上或真实用户数据。

| 页面 | 修改前星空绘制/秒 | 修改后星空绘制/秒 | 修改前 LCP (ms) | 修改后 LCP (ms) | 修改后 CLS |
| --- | ---: | ---: | ---: | ---: | ---: |
| 首页 | 37.5 | 146.9 | 133 | 67 | 0.000 |
| 文章列表 | 36.4 | 213.3 | 159 | 117 | 0.045 |
| 长文章样例 | 39.7 | 216.1 | 179 | 169 | 0.001 |
| 归档 | 36.9 | 188.3 | 55 | 64 | 0.005 |
| 相册 | 40.3 | 228.3 | 57 | 49 | 0.002 |
| 音乐 | 40.0 | 216.1 | 39 | 53 | 0.002 |
| 关于 | 39.4 | 230.8 | 101 | 97 | 0.051 |

浏览器测试环境的 `requestAnimationFrame` 频率高于 60Hz，因此表中的数值表示星空不再被旧版 22ms 门槛限制，不应解读为显示器实际帧率。修改后采样中绘制间隔超过 33ms 的最高占比为 0.58%。

- 连续 20 次首页/归档 PJAX 往返：修改前 `window` 滚动监听器 4 → 24，修改后 5 → 5。
- 同页垃圾回收后的 DOM 计数：节点 1188 → 1195，监听器 176 → 181，没有随 20 次切换线性增长。
- 首屏桌面主图候选从 485658 B 降至 355342 B，PSNR 约 40.2 dB；原图仍作为最大候选和灯箱链接保留。
- 390 × 844、DPR 3 的移动端通过全部页面检查；星空画布检测到 11023 个非透明像素。
- 交互、搜索、长文章进度、音乐跨页播放、PJAX 失败恢复、暗色和减少动态效果检查均通过。
- 统计和评论使用网络拦截模拟，分别验证每页只计一次和只提交一次，没有向线上写入测试数据。

当前环境没有真实用户 INP 数据。交互观察器记录的受控事件最长 64ms，低于 200ms 目标；正式 INP 应以部署后的 Cloudflare Web Analytics 或其他 RUM 数据为准。

## 复现

```powershell
npm run check
npm run check:performance-build
npm run server
```

另开终端后，可以使用 Playwright CLI 运行检查脚本：

```powershell
npx --yes --package @playwright/cli playwright-cli -s=sujing-perf open http://127.0.0.1:4000/ --config tools/playwright-performance.config.json
npx --yes --package @playwright/cli playwright-cli -s=sujing-perf run-code --filename tools/performance-browser.js
npx --yes --package @playwright/cli playwright-cli -s=sujing-perf run-code --filename tools/performance-flows.js
npx --yes --package @playwright/cli playwright-cli -s=sujing-perf run-code --filename tools/performance-edge-cases.js
npx --yes --package @playwright/cli playwright-cli -s=sujing-perf run-code --filename tools/performance-services.js
```

浏览器产物写入 `output/playwright/`。基线辅助脚本会在忽略的 `tmp/` 下创建隔离副本，不修改当前工作树：

```powershell
node tools/prepare-performance-baseline.js
```
